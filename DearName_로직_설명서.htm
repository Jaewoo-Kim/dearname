1. 이 문서를 읽기 전에

DearName은 사주명리학 이론을 바탕으로 한 온라인 작명 서비스입니다. 현재 두 가지 서비스를 제공합니다.

구분 셀프 분석 프리미엄 작명
목적 사용자가 직접 고른 이름의 좋고 나쁨을 확인 사주에 맞는 이름 후보를 AI가 자동 생성 및 추천
입력값 이름(한글+한자) + 생년월일시 성씨(한자) + 성별 + 생년월일시 + 희망 성향
출력 발음 분석, 자원오행 평가, 81수리 결과 상위 이름 후보 목록 + Claude AI 작명 보고서
사주 분석 깊이 8글자 단순 카운트 (직관적 설명 목적) 지장간 비율 가중치 포함 (정밀 분석)
📌 작명가 검토 요청 배경
저희 서비스의 각 채점 항목과 가중치가 실제 작명 이론과 부합하는지 전문가 관점에서 검토해 주시기를 요청드립니다. 특히 ①각 항목의 채점 기준이 적절한지, ②항목 간 우선순위가 이론과 맞는지, ③빠진 중요 항목이 있는지를 중심으로 의견 주시면 감사하겠습니다.

2. 전문 용어 해설

이 문서에는 사주명리학 용어가 자주 등장합니다. 비전문가도 이해할 수 있도록 주요 용어를 먼저 정리합니다.

2-1. 오행(五行) 기본 개념

오행 상징 초성(발음) 자연 이미지
木 (목) 나무 ㄱ, ㅋ, ㄲ 성장, 생명력, 봄
火 (화) 불 ㄴ, ㄷ, ㄹ, ㅌ, ㄸ 열정, 빛, 여름
土 (토) 흙 ㅇ, ㅎ 안정, 신뢰, 환절기
金 (금) 쇠 ㅅ, ㅈ, ㅊ, ㅆ, ㅉ 결단, 의리, 가을
水 (수) 물 ㅁ, ㅂ, ㅍ, ㅃ 지혜, 유연함, 겨울

오행의 상생과 상극

  • 상생(相生) — 서로 도와주는 관계: 木→火→土→金→水→木 (앞의 것이 뒤의 것을 키움)
  • 상극(相剋) — 서로 억누르는 관계: 木→土, 火→金, 土→水, 金→木, 水→火
  • 비화(比和) — 같은 오행끼리: 서로 돕는 관계로 상생과 동일하게 봄
예시: "김서연"이라는 이름에서
· 김(ㄱ) → 木, 서(ㅅ) → 金, 연(ㅇ) → 土
· 木(김)→金(서): 상극 ❌ / 金(서)→土(연): 상극 ❌
· 인접 쌍 2개 중 상극 1개 → "좋음" 등급 (상극이 과반 미만)

2-2. 사주(四柱)와 팔자(八字)

기둥(柱) 내용 구성
연주(年柱) 태어난 해 천간(干) + 지지(支) = 2글자
월주(月柱) 태어난 달 천간 + 지지 = 2글자
일주(日柱) 태어난 날 천간 + 지지 = 2글자
시주(時柱) 태어난 시간 천간 + 지지 = 2글자

4기둥 × 2글자 = 총 8글자 → 팔자(八字). 천간(甲乙丙丁戊己庚辛壬癸)은 10종, 지지(子丑寅卯辰巳午未申酉戌亥)는 12종입니다.

2-3. 지장간(支藏干)

지지(地支) 속에 숨어있는 천간의 기운입니다. 예를 들어 子(자)는 겉으로 水이지만 내부에 壬(40%)·癸(60%)가 들어있습니다.

셀프 분석 vs 프리미엄의 차이가 여기서 납니다.
· 셀프 겉면 오행(지지 정기)만 1개로 카운트 → 직관적 설명에 적합
· 프리미엄 지장간 비율 포함 → 보다 정밀한 오행 점수 계산

2-4. 자원오행(字源五行)

한자가 가진 오행 속성입니다. 한자의 뜻·부수·형태에서 비롯됩니다.

  • 水(수): 洙, 淳, 海, 源 등 水 부수(氵) 한자
  • 木(목): 林, 柳, 桂 등 木 부수(木·木旁) 한자
  • 예: 서(瑞) = 金 속성, 연(玟) = 土 속성

2-5. 발음오행(소리오행)

한글 이름 글자의 첫소리(초성)가 가진 오행입니다. 한자와 무관하게 소리 자체의 오행을 분석합니다.

2-6. 수리학(數理學) — 81수리

이름 각 글자의 획수를 더해 얻은 숫자의 길흉을 판단하는 이론입니다. 1~81까지 각 숫자에 등급이 있습니다.

4格(격) 계산 방식 (두 글자 이름 기준) 의미
원격(元格) 이름 첫 글자 + 이름 둘째 글자 획수 초년운 (어린 시절)
형격(亨格) 성 획수 + 이름 첫 글자 획수 중년운 (사회·직업)
이격(利格) 성 획수 + 이름 둘째 글자 획수 장년운 (가정·재물)
정격(貞格) 성 + 이름 모든 글자 획수 합산 말년운 (인생 전체)
⚠️ 81수리 등급 체계
대길(大吉) > 길(吉) > 평(平) > 흉(凶) > 대흉(大凶)
저희 서비스에서는 대흉이 하나라도 있거나, 말년격(정격)이 평·흉이면 해당 이름 후보를 자동 탈락시킵니다.

2-7. 대운(大運)

10년 단위로 바뀌는 운의 흐름입니다. 몇 살부터 시작하는지는 성별과 태어난 해의 천간(양간·음간)에 따라 달라집니다. 프리미엄 서비스는 대운이 약한 시기(특히 중년·노년)를 보완하는 이름에 가점을 줍니다.

2-8. 조후(調候)

계절(월지)에 따른 온도 조절 개념입니다.

  • 여름(巳·午·未월) 태생인데 水 기운이 부족하면 → 물(水) 기운 이름이 시급
  • 겨울(亥·子·丑월) 태생인데 火 기운이 부족하면 → 불(火) 기운 이름이 시급

2-9. 통관(通關)

사주 안에서 두 오행이 서로 강하게 충돌할 때, 두 세력을 중재해 주는 오행이 필요한 상황입니다.

  • 木↔土 대립 → 火로 중재 / 火↔金 대립 → 土로 중재 (오행 순환 원리 적용)

2-10. 억부법(抑扶法)과 용신(用神)

일간(태어난 날의 천간)을 기준으로 사주 전체가 강한지(신강) 약한지(신약)를 판단한 뒤, 균형을 잡아 줄 핵심 오행을 용신(用神)으로 선정하는 이론입니다.

  • 신강(身强) — 일간이 너무 강함 → 억제하는 오행(식·재·관)이 용신
  • 신약(身弱) — 일간이 약함 → 돕는 오행(인성·비겁)이 용신
  • 중화(中和) — 균형 상태 → 용신 불필요
  • 희신(喜神): 용신을 도와주는 오행 / 기신(忌神): 용신을 해치는 오행

2-11. 종격(從格) — 특수격

사주 내 한 오행이 압도적으로 강할 때(점수 60점 이상), 그 강한 기운을 억누르려 하지 않고 순응하는 특수한 격국입니다. 일반 사주와 용신 선정 원리가 반대입니다.

종격 유형 지배 오행 이름에 권장 이름에 금지
종왕/종강격木 압도木·水金
종아격火 압도火·木水
전왕격土 압도土·火木
종재격金 압도金·土火
종살격水 압도水·金土

2-12. 분파(分破) 한자

글자를 좌우 또는 상하로 나누면 구성 요소가 서로 분리·충돌하는 구조의 한자입니다. 이름 전체 글자(성+이름)가 모두 분파 구조이면 이름의 기운이 분산된다고 봅니다.

예시 분파 한자: 朴(박), 林(림), 安(안) 등 약 400자 목록 관리 중

3. 공통 기반: 사주 계산 방식

3-1. 만세력 데이터 기반

동추원 만세력 데이터를 사용합니다. 1921년~2040년 출생자를 지원하며, 절기 날짜와 시간까지 분 단위로 반영해 월주를 정확하게 계산합니다.

3-2. 지방시 보정

한국 내 도시별로 동경 135도 표준시와의 차이를 초 단위로 보정합니다. 서울은 약 32분 차이가 납니다. 이 보정을 적용하면 실제 태양시 기준으로 시주가 결정됩니다.

3-3. 야자시(夜子時) 처리

밤 11시~12시(23:00~24:00)에 태어난 경우 자시(子時)가 당일에 속하는지 다음날에 속하는지는 학파에 따라 다릅니다. 저희 서비스는 이 옵션을 선택할 수 있게 했습니다.

3-4. 오행 점수 계산 (프리미엄 전용 정밀 버전)

총 100점을 4기둥 8글자에 배분합니다.

  • 천간(干): 각 기둥의 천간 오행에 10점
  • 지지(支): 지장간 비율에 따라 15점 분배 (초기 15%·중기 25%·정기 60%)

예: 午(오)는 丙(15%)=2.25점, 己(25%)=3.75점, 丁(60%)=9점으로 화(火)와 토(土)에 나뉘어 배분

4. 셀프 분석 로직

사용자가 직접 이름(한글 + 한자)을 입력하면 세 가지 관점에서 분석합니다.

4-1. 발음 분석 (소리오행 분석)

무엇을 보나요? 성씨+이름 전체 글자의 초성 오행이 이웃 글자 사이에서 상생인지 상극인지 판단합니다.

계산 방법

  1. 각 글자의 첫소리(초성) 추출 → 오행 변환
  2. 인접한 두 글자 쌍마다 상생/비화(○) 또는 상극(✕) 판정
  3. 상극 쌍 수(badCount)와 전체 인접 쌍 수(total) 비교
등급 조건 설명
매우 좋음 상극 쌍 = 0개 모든 인접 글자가 상생 또는 비화
좋음 상극 쌍 × 2 ≤ 전체 쌍 상생이 상극보다 많음
나쁨 그 외 상극이 과반 이상
매우 나쁨 상극 쌍 = 전체 쌍 모든 인접 글자가 상극
예시: "김서연"
김(ㄱ=木) → 서(ㅅ=金) → 연(ㅇ=土)
· 木↔金: 상극 ✕ / 金↔土: 상극 ✕
· 외자 이름: total=2, badCount=1 → 상극 1×2=2 ≤ 2 → 좋음
예시: "나라" (성씨 포함하지 않은 경우)
나(ㄴ=火) → 라(ㄹ=火)
· 火↔火: 비화 ○ / badCount=0 → 매우 좋음

4-2. 자원오행 평가 (한자오행과 사주 비교)

무엇을 보나요? 사용자가 입력한 한자 이름의 자원오행이 태어난 사람의 사주 오행과 잘 어울리는지 판단합니다.

셀프 분석 전용 사주 해석 방식

셀프 전용 셀프 분석에서는 지장간 비율 없이 8글자 단순 카운트로 오행 분포를 파악합니다. 각 글자의 대표 오행에 1점씩 배정해 총 8점 배분.

판정 로직 (우선순위 순)

① 종격(특수격) 판정 — 최우선

지장간 가중 점수 기준으로 한 오행이 60점 이상이고 그 오행을 극하는 오행이 5점 미만이면 종격으로 판정됩니다.

  • 이름에 극오행 포함 → "나쁨"
  • 이름에 지배오행 또는 지원오행 포함 → "매우 좋음"
  • 중립 → "좋음" (더 좋은 오행 안내)

② 통관 판정 (프리미엄 모드 전용)

사주에서 두 오행이 모두 25점 이상으로 강하게 대립하는 경우에만 적용됩니다. 셀프 분석에서는 이 판정 없이 아래 단계로 넘어갑니다.

③ 일반 오행 부족/과다 판정

단순 8자 카운트를 기준으로 빈 오행(0개)과 과다 오행(가장 많은 오행)을 파악합니다.

  • 이름이 빈 오행을 보완하면 → "매우 좋음" 또는 "좋음"
  • 이름이 편중된 오행을 더 강화하면 → "나쁨"
  • 균형 사주(빈 오행 없음)는 상대적 강약으로 세분화 평가

4-3. 81수리 확인

사용자가 입력한 이름의 획수를 바탕으로 원격·형격·이격·정격을 계산하고 각 격의 등급(대길/길/평/흉/대흉)을 표시합니다.

셀프 분석에서는 참고 정보로 표시하며, 등급에 따라 이름 변경을 권장하는 안내가 제공됩니다.

5. 프리미엄 작명 로직

두 단계로 이루어집니다: ①이름 설계도(NameSpec) 생성 → ②수만 개 후보 채점.

5-1. 이름 설계도(NameSpec) 생성

무엇인가요? 사주를 분석해 "이 사람에게는 어떤 오행의 이름이 필요한가"를 결정하는 과정입니다. 결과물: prefer(권장 오행 목록) + avoid(금지 오행 목록) + 전략(reinforce/balance)

아래 4단계 우선순위로 순서대로 적용됩니다. 앞 단계에서 결론이 나면 뒷 단계는 건너뜁니다.

1순위: 긴급진단

아래 세 가지 위급 상황 중 해당하는 것이 있으면 즉시 보완 오행을 결정합니다.

진단 유형 발동 조건 처방
조후(調候)
온도 긴급		 여름 태생(巳·午·未월) + 水 점수 < 15점
겨울 태생(亥·子·丑월) + 火 점수 < 15점		 水(여름) 또는 火(겨울) 즉시 권장
통관(通關)
충돌 중재		 상극 관계의 두 오행이 각 25점 이상으로 대립 두 오행을 중재하는 오행 권장
고립(孤立)
약자 보호		 오행 점수 5점 미만 + 그 오행을 극하는 오행이 40점 이상 고립된 오행을 생해주는 오행 권장

1.5순위: 억부법(抑扶法) 용신

일간(태어난 날 천간)을 기준으로 신강/신약을 판단합니다.

  • 신강: 인비(인성+비겁) 점수 × 1.2 > 식재관(식상+재성+관살) 점수 → 식재관 중 가장 약한 오행이 용신
  • 신약: 식재관 점수 × 1.2 > 인비 점수 → 인성·비겁 중 가장 약한 오행이 용신
  • 긴급진단(1순위)이 먼저 적용된 경우에는 용신·희신을 추가로 prefer에 반영하지 않음

2순위: 종격(從格) — 특수격

지장간 가중 점수로 한 오행이 60점 이상 + 그 극오행이 5점 미만이면 종격으로 판정합니다. 이 경우 강한 기운에 순응하는 전략(strategy: 'reinforce')으로 이름을 설계합니다.

종격 설계 원칙:
· prefer = [지배오행, 지원오행] (예: 水 종살격 → 水·金 권장)
· avoid = [극오행] (예: 水 종살격 → 土 금지)
· 일반 중화 이론과 반대 방향 — "강한 기운을 억제하지 않고 타고 흐름"

2.5순위: 대운 흐름 보완

중년(35~59세)과 노년(60세 이상)의 대운에서 약한 오행(20점 미만)을 파악합니다. 노년 대운의 약오행에는 가중치(2배)를 부여합니다. 세 번 이상 약하게 나오는 오행을 prefer에 추가합니다.

3순위: 일반격 중화 보완

앞 단계에서 결론이 안 난 경우, 전체 오행 점수에서 부족한 오행(극약·약함)을 prefer에, 과다한 오행(강함·태과)을 avoid에 넣어 균형을 맞춥니다.

5-2. 이름 후보 채점 로직

필터 조건

등급 원·형·이격 점수 정격(말년) 점수

4격 전부 대길이면 올클 보너스 +30점 추가.
[C] 발음오행 상생/상극

[F] 성향 보너스
사용자가 선택한 희망 성향(예: 리더십, 예술성 등)에 연관된 오행이 이름에 포함되면 +3점/개 (최대 +15점).
[G] 대운 보완 가점
중년·노년 대운에서 약한 오행을 이름이 포함하면 가점, 강한 오행을 이름이 포함하면 감점. 범위 –20~+30점.
[H] 운 중심 수리 가점
사용자가 '재물운', '리더십', '지혜', '건강' 중 하나를 선택한 경우, 81수리 중 해당 운에 유리한 숫자에 4격이 해당될 때마다 +8점.
[I] 부모 사주 조화
(선택 입력) 부모의 사주에서 가장 강한 오행이 이름에 있으면 –5점, 가장 약한 오행이 이름에 있으면 +5점.
[J] 동음 패널티
· 성씨와 이름 첫 글자의 발음이 같으면 (예: 서서○○) –30점
· 이름 두 글자의 발음이 같으면 (예: ○○연연) –20점
[K] 현대성 보정
· 현대에 인기 있는 음절을 이름에 사용하면 소폭 가점
· 구식으로 느껴지는 음절을 사용하면 –3점/개
⚠️ 상한 점수 200점
A~K를 모두 더한 점수가 200점을 넘더라도 최대 200점으로 제한합니다.
